# Security Policy

## Unterstützte Version

Während des Feature Freeze wird grundsätzlich die jeweils aktuelle v1.x-Version gepflegt.

## Sicherheitsproblem melden

Bitte veröffentliche keine Passwörter, Cookies, Tokens, lokalen Pfade mit sensiblen Informationen oder andere Geheimnisse in einem öffentlichen Issue.

Wenn im GitHub-Repository private Vulnerability Reports / Security Advisories aktiviert sind, nutze bevorzugt diesen privaten Kanal. Andernfalls beschreibe in einem öffentlichen Issue nur die nicht-sensiblen Auswirkungen und teile keine Geheimnisse oder persönlichen Daten.

## Lokale Daten

`Manhwa-Watcher-Data/`, Datenbanken, Logs, Backups und heruntergeladene Medien sind bewusst über `.gitignore` ausgeschlossen und sollten nicht in ein öffentliches Repository aufgenommen werden.
