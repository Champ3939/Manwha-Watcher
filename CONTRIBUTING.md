# Contributing

Danke für dein Interesse an Manhwa Watcher.

## Feature Freeze

Seit v1.1.0 liegt der Fokus auf:

- Bugfixes
- Stabilität
- Performance
- Kompatibilität mit Webseiten-/DOM-Änderungen
- Tests und Dokumentation

Große neue Features sollten vor einer Implementierung zuerst als Issue diskutiert werden.

## Entwicklungsablauf

1. Fork/Branch erstellen.
2. Änderungen möglichst klein und klar halten.
3. `npm run check` ausführen.
4. Keine lokalen Daten, Downloads, Datenbanken, Logs oder Zugangsdaten committen.
5. Pull Request mit kurzer Beschreibung und nachvollziehbaren Testschritten erstellen.

## Connectoren

Connector-Änderungen sollten generisch und wartbar bleiben. Bitte keine Zugangsdaten, Cookies, Tokens oder andere private Sitzungsdaten in Connector-Dateien committen.

## Rechtliches

Beiträge dürfen keine urheberrechtlich geschützten Medieninhalte enthalten. Automatisierte Download-Funktionen sind nur für Inhalte/Quellen vorgesehen, deren Nutzung entsprechend erlaubt ist.
