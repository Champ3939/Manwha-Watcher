# Manhwa Watcher v1.2.0 – Online Library

This release adds an Aniyomi-style online library mode.

- Save series without downloading chapters.
- Only metadata, source URLs, covers and reading progress are stored locally.
- Search the saved online library across all sources.
- Open saved series to fetch their chapter list live.
- Use **Lesen** on a chapter to open the source reader without creating a CBZ.
- **Weiterlesen** remembers and reopens the last chapter read.
- Existing offline CBZ downloads and Syncthing/Anyomi sync continue to work normally.
