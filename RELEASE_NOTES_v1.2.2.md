# Manhwa Watcher v1.2.2 – Chapter Read Status

The Online Library now tracks every chapter you read.

- Read chapters show a visible `✓ GELESEN` badge.
- Read rows receive a subtle green highlight.
- The series header shows `Gelesen: X/Y`.
- Reading a chapter marks it automatically.
- Use the `✓ Gelesen` button to mark a chapter unread again.
- Existing v1.2.1 `Zuletzt gelesen` progress remains recognized.
- Only metadata is stored in SQLite; no CBZ or image is saved by this feature.
